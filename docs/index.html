FPI Number Representation Demonstrator

The same information can be written many ways — as text, as character codes, as hexadecimal, as binary, even as Roman numerals. Those are representations: change the notation and you can always change it back.

A UUIDv5 is not a representation. It is a hash-derived identifier. Given the same namespace and value it always produces the same UUID, which is what makes it reproducible and auditable — but the UUID is not a reversible encoding of its inputs. You cannot read the identifier value back out of it, and two different source identifiers for the same payer do not converge on one FPI.

    What this does and does not mean

    • Deterministic: the same system and value always give this same UUID.
    • One-way: the inputs cannot be recovered from the UUID. The arrows above only run left to right.
    • Non-converging: change the system or a single character of the value and you get an unrelated UUID. Different source identifiers for one payer do not merge into a single FPI.

    Representation views

    Both inputs as numbers. Every character becomes its ASCII (Unicode code point) value — including hyphens and letters — which is what lets a value such as TX-68775 be written numerically at all.

    Reversible, for contrast

    Arithmetic runs both ways. Add 12, then subtract 12, and you are back where you started — the operation carries enough information to undo it.

    There is no such inverse for UUIDv5. No operation takes back to its system and value. The only way to confirm an FPI is to recompute it from a declared source and check that the two match — which is exactly what the derivation above does.

    Complete Roman numeral output

    Notation for values beyond the ordinary Roman range

    Ordinary Roman numerals stop at 3,999. The numbers here go far past that, so each wrapping pair of parentheses multiplies by 1,000 — an ASCII stand-in for the vinculum, the overbar used classically for the same purpose.

    • (X) = 10 × 1,000 = 10,000
    • ((I)) = 1 × 1,000 × 1,000 = 1,000,000
    • ((I))(I)CMLXXXVII = 1,001,987
    • nulla = zero, which Roman numerals have no symbol for
